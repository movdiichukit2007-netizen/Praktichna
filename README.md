# Практична робота: Розробка узагальненого репозиторію сутностей
## Тема: Розробка узагальненого класу

### Висновки:
1. Обмеження where T : Model дозволяє звертатися до властивості Id всередині узагальненого репозиторію.
2. Статичне поле зберігає колекцію сутностей у пам'яті програми.
3. Дані Posting та ContactPerson не змішуються, оскільки для кожного типу T створюється власне статичне поле.
